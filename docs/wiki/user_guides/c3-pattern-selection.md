# C3 Pattern Selection (Unified Checkbox UX)

## Что изменилось (V2.3.S4a)

В C3 выбор паттернов переведен на чекбоксы, чтобы совпадать с C2:

1. `Include` — включить паттерн в предпочтения генерации.
2. `Exclude` — исключить паттерн из рассмотрения.

## Как пользоваться

1. Откройте вкладку `Pattern Library + RAG`.
2. Найдите нужный паттерн через поиск/фильтр.
3. Отметьте `Include` или `Exclude` чекбоксом.
4. Для возврата в нейтральный режим снимите чекбокс.

## Что важно

1. Выбор сохраняется в arena-состоянии и используется в следующей генерации кандидатов.
2. Детали паттерна и схема (accordion) доступны отдельно и не влияют на selection.
3. Модель выбора доменно остается `include/exclude/neutral`, но UX теперь единообразный с C2.
