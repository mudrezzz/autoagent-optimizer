# Release Note: V2.3.S5a

## Slice

`V2.3.S5a - C4 UX unification + Dataset Editor`

## User-visible Changes

1. C4 dataset list now matches C2/C3 row-list UX and behavior.
2. Added dataset checkboxes and explicit `Save` action for arena assignment.
3. `Details` now shows first 5 dataset rows preview.
4. `Edit` opens dedicated editor screen with breadcrumbs.
5. Editor now supports add/delete/edit rows, JSONL import, save changes, validate, save version.

## Why

To keep UX consistent in Battle Workspace and provide a dedicated screen for deep work with a specific dataset.

## Technical Summary

1. Extended store with `assigned_dataset_ids` in `dataset_studio`.
2. Added endpoint `POST /api/arenas/{id}/datasets/assign`.
3. Extended C4 state payload with `assigned_dataset_ids` and `preview_rows`.
4. Split frontend C4 into `list`/`edit` modes.
5. Updated unit/integration/e2e smoke tests for new UX flow.
