# Release Note: V2.3.S5a

## Slice

`V2.3.S5a - C4 UX unification + Dataset Editor`

## User-visible changes

1. C4 dataset list теперь визуально и поведенчески совпадает с C2/C3 row-list паттерном.
2. Добавлены чекбоксы dataset-ов и явное действие `Save` для назначения на арену.
3. `Details` показывает превью первых 5 строк dataset.
4. `Edit` открывает отдельный editor-screen с breadcrumbs.
5. В editor доступны: add/delete/edit rows, JSONL import, save changes, validate, save version.

## Why

Чтобы сохранить UX-единообразие в Battle Workspace и дать отдельный рабочий экран для глубокой работы с конкретным датасетом.

## Technical summary

1. Store расширен `assigned_dataset_ids` в `dataset_studio`.
2. Добавлен endpoint `POST /api/arenas/{id}/datasets/assign`.
3. C4 state payload дополнен `assigned_dataset_ids` и `preview_rows`.
4. Frontend C4 разделен на `list`/`edit` режимы.
5. Обновлены unit/integration/e2e smoke тесты под новый UX-поток.
