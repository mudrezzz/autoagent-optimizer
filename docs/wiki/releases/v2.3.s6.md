# Release Note: V2.3.S6

## Slice

`V2.3.S6 - C4 Metrics & Evaluators Studio v0`

## User-visible changes

1. В C4 появился отдельный блок `Metrics & evaluators studio`.
2. Пользователь настраивает comparative metrics (чекбоксы + веса).
3. Пользователь настраивает diagnostic signals (чекбоксы).
4. Пользователь выбирает evaluators (чекбоксы).
5. Пользователь задает budget limits (`max_cases`, `max_llm_calls`, `max_cost_usd`).
6. Появились действия `Validate profile` и `Save version` для evaluation profile.

## Why

Чтобы профиль оценки стал управляемым из UI и не был захардкожен в backend-логике.

## Technical summary

1. Store расширен блоком `evaluation_studio`.
2. Добавлены API-эндпоинты `/api/arenas/{id}/evaluation/*`.
3. Frontend C4 получил новую evaluation-панель с сохранением/валидацией/версионированием.
4. Обновлены unit/integration/e2e smoke тесты под evaluation flow.
