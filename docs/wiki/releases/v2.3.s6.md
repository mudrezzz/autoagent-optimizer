# Release Note: V2.3.S6

## Slice

`V2.3.S6 - C4 Metrics & Evaluators Studio v0`

## User-visible Changes

1. Added dedicated `Metrics & evaluators studio` block in C4.
2. Users can configure comparative metrics (checkboxes + weights).
3. Users can configure diagnostic signals (checkboxes).
4. Users can configure evaluators (checkboxes).
5. Users can configure budget limits (`max_cases`, `max_llm_calls`, `max_cost_usd`).
6. Added `Validate profile` and `Save version` actions for evaluation profile.

## Why

To make evaluation profile configurable from UI instead of hardcoded backend logic.

## Technical Summary

1. Extended store with `evaluation_studio` block.
2. Added API endpoints `/api/arenas/{id}/evaluation/*`.
3. Added C4 evaluation panel in frontend with save/validate/versioning.
4. Updated unit/integration/e2e smoke tests for evaluation flow.
