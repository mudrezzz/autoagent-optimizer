# Release Note: V2.3.S5

## Slice

`V2.3.S5 - C4 Dataset Studio v0`

## User-visible changes

1. В Battle Workspace включен capability `C4 Dataset Studio`.
2. Появился lifecycle dataset: create/select/edit/validate/save-version.
3. Добавлен manual row editor и JSONL import (replace rows).
4. В UI отображаются validation issues и список dataset versions.

## Why

Чтобы пользователь мог готовить и версионировать тестовые данные прямо в продукте до запуска оптимизации.

## Technical summary

1. Добавлен arena-scoped `dataset_studio` в `optimizer.workspace.registry_store`.
2. Добавлены API-эндпоинты `/api/arenas/{id}/datasets/*` в `optimizer.frontend.dev_server`.
3. C4 переведен в `enabled` в capability contracts.
4. Реализован C4 UI в `frontend/src/App.tsx` и типы/API клиент для C4.
5. Расширены unit/integration/e2e smoke тесты для C4-пути.

## Verification

1. `npm run test -- --run src/__tests__/app.workspace.test.tsx`
2. `python -m pytest tests/unit/test_frontend_contracts.py -q`
3. `python -m pytest tests/integration/test_frontend_dev_server.py -q`
4. `python -m pytest tests/e2e/test_frontend_shell_smoke_script.py -q`
