# Release Note: V2.3.S5

## Slice

`V2.3.S5 - C4 Dataset Studio v0`

## User-visible Changes

1. Enabled capability `C4 Dataset Studio` in Battle Workspace.
2. Added dataset lifecycle: create/select/edit/validate/save-version.
3. Added manual row editor and JSONL import (replace rows).
4. Added validation issues and dataset versions list in UI.

## Why

To let users prepare and version test data directly in product before running optimization.

## Technical Summary

1. Added arena-scoped `dataset_studio` to `optimizer.workspace.registry_store`.
2. Added API endpoints `/api/arenas/{id}/datasets/*` in `optimizer.frontend.dev_server`.
3. Set C4 as `enabled` in capability contracts.
4. Implemented C4 UI in `frontend/src/App.tsx` and C4 API/types client.
5. Extended unit/integration/e2e smoke tests for C4 flow.

## Verification

1. `npm run test -- --run src/__tests__/app.workspace.test.tsx`
2. `python -m pytest tests/unit/test_frontend_contracts.py -q`
3. `python -m pytest tests/integration/test_frontend_dev_server.py -q`
4. `python -m pytest tests/e2e/test_frontend_shell_smoke_script.py -q`
