# Release Note: V2.4.S6

## Slice

`V2.4.S6 - Contextual right chat (tab-scoped copilot)`

## Summary

Right chat is now capability-aware and can execute contextual actions for the active wizard step instead of behaving as C2-only chat.

Supported steps:

1. `C2` - task chat + candidate generation.
2. `C4` - `add_dataset_row`.
3. `C5` - `enable_default_metrics`.
4. `C5s` - `auto_map_stage_mappings` / `add_mapping_row`.
5. `C6` - `autofill_matrix_links`.
6. `C7` - `validate_optimizer_setup`.

## What Changed

1. Extended chat API payload with `capability_id` and `context_action`.
2. Added backend contextual action router for `C4/C5/C5s/C6/C7`.
3. Added `copilot_context` in chat response:
4. `resolved_action`,
5. `allowed_actions`,
6. `summary`.
7. Frontend chat composer now adapts placeholder, action button label, and hints by active capability.
8. Non-C2 chat actions trigger targeted state refresh of the active step data.
