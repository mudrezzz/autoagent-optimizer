# Release Note: V2.4.S7

## Slice

`V2.4.S7 - Runtime snapshot UX cleanup`

## Summary

The workspace no longer renders raw runtime JSON inside capability panels. Runtime snapshot inspection moved into a dedicated `Debug` drawer.

## What Changed

1. Removed inline `Runtime snapshot` panels from workspace capability content.
2. Added `Debug` button in workspace topbar.
3. Added `Debug snapshot` drawer with:
4. active capability,
5. progress/stage metadata,
6. battle id,
7. latest raw JSON payload.
8. Kept `Export snapshot` as a file download action.
9. Updated frontend regression test to verify drawer open/close behavior.

## QA

1. `npm --prefix frontend run test -- src/__tests__/app.workspace.test.tsx`
2. `npm --prefix frontend run build`
3. `python -m pytest tests/unit/test_frontend_contracts.py -q`
4. `python -m pytest tests/e2e/test_frontend_shell_smoke_script.py -q`
