# Release Note: V2.3.S6a

## Slice

`V2.3.S6a - C4 corrective UX (Datasets/Metrics split) + wiki screenshot governance`

## User-visible Changes

1. Added explicit C4 tab navigation: `Datasets` and `Metrics`.
2. Dataset flow is now separated from evaluation profile setup.
3. Comparative/diagnostic/evaluators/budget settings are available only in `Metrics` tab.
4. Added real UI screenshots for C4 (`Datasets`, `Metrics`) and C5 (`Optimizer Setup`) to user guides.

## Why

To remove mixed UX flows in C4, improve readability, and keep documentation verifiable against real UI.

## Technical Summary

1. `frontend/src/App.tsx`: added C4 tab switch (`datasets`/`metrics`) with split rendering.
2. `frontend/styles.css`: added C4 tab styles.
3. `optimizer/workspace/registry_store.py`: fixed evaluation store consistency (profile helpers + legacy mirror sync).
4. `frontend/src/__tests__/app.workspace.test.tsx`: updated C4 flow checks for `Metrics` tab.
5. `docs/wiki/user_guides/c4-dataset-studio.md`, `docs/wiki/user_guides/c5-optimizer-setup.md`: added real screenshots.
