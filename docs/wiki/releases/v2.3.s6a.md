# Release Note: V2.3.S6a

## Slice

`V2.3.S6a - C4 corrective UX (Datasets/Metrics split) + wiki screenshot governance`

## User-visible changes

1. В C4 появилась явная навигация вкладками: `Datasets` и `Metrics`.
2. Dataset-поток теперь отделен от настройки evaluation profile.
3. Настройки comparative/diagnostic/evaluators/budget доступны только во вкладке `Metrics`.
4. В user guides добавлены реальные скриншоты C4 (`Datasets`, `Metrics`) и C5 (`Optimizer Setup`).

## Why

Чтобы убрать смешение UX-потоков в C4, повысить читаемость интерфейса и сделать пользовательскую документацию наглядной и проверяемой по реальному UI.

## Technical summary

1. `frontend/src/App.tsx`: добавлен C4 tab switch (`datasets`/`metrics`) и раздельный рендер потоков.
2. `frontend/styles.css`: добавлены стили табов C4.
3. `optimizer/workspace/registry_store.py`: закрыта консистентность evaluation store (profile helpers + legacy mirror sync).
4. `frontend/src/__tests__/app.workspace.test.tsx`: обновлены проверки C4 flow с учетом вкладки `Metrics`.
5. `docs/wiki/user_guides/c4-dataset-studio.md`, `docs/wiki/user_guides/c5-optimizer-setup.md`: добавлены реальные скриншоты.

2. `python -m pytest tests/integration/test_frontend_dev_server.py -q`
3. `python -m pytest tests/unit/test_workspace_registry_store.py -q`
