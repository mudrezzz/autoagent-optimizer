# Release Note: V2.4.S4

## Slice

`V2.4.S4 - Evaluator x Metric matrix v0`

## User-visible Changes

1. C6 now includes explicit `Evaluator x Metric` matrix with per-cell toggles.
2. Matrix supports both comparative metrics and diagnostic signals.
3. Added `Save matrix` action to persist evaluator coverage mapping.
4. Evaluation validation now blocks profile if enabled metric/signal has no enabled evaluator link.

## Why

To decouple metric definitions from evaluator methods and enforce explicit coverage before optimization runs.

## Technical Summary

1. Added profile field `evaluator_metric_links` to evaluation studio state.
2. Added backend endpoint `POST /api/arenas/{arena_id}/evaluation/matrix/save`.
3. Added store API `save_arena_evaluation_evaluator_metric_links(...)`.
4. Extended validation report with error `evaluator_metric_coverage_gap`.
5. UI C6 renders matrix table and saves matrix links via new API call.
