# Release I5.S3

## Slice

`I5.S3 Metric-Crafting Agent + HITL loop v0`

## What Changed

1. Added backend metric proposal service in `optimizer.evaluation.metric_crafting`.
2. Added `POST /api/arenas/{arena_id}/evaluation/metrics/suggest`.
3. Added `POST /api/arenas/{arena_id}/evaluation/metrics/proposals/{proposal_id}/apply`.
4. Added C5 Metrics proposal UI with checkbox selection and explicit apply.
5. Added contextual chat action `suggest_metrics` for C5.
6. Extended evaluator adapter support for stylizer-specific metrics.

## Why It Matters

Metrics are task-specific and should be created with assistant help, but profile changes must remain human-approved.

This slice establishes the first MetricOps loop:

1. propose,
2. review,
3. apply selected,
4. version profile,
5. refresh evaluator coverage.
