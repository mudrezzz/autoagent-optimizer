# Release I5.S3a

## Slice

`I5.S3a Stage Mapping manual confirmation fix`

## What Changed

1. Manual stage mapping confirmation now resolves `ambiguous` auto-map rows.
2. Backend save normalizes manually confirmed single-node rows to `bound` with `source=manual`.
3. Frontend marks edited Stage Mapping rows as manual and shows `needs confirmation` for ambiguous rows.
4. Validation deduplicates repeated stage mapping errors by stage/candidate.

## Why It Matters

Auto-map should be conservative, but a human confirmation must be accepted as a HITL decision.
Before this slice, users could confirm `Pattern Cleaner / synthesis / rewrite_draft`, save the mapping, and still receive `stage_mapping_ambiguous`.
