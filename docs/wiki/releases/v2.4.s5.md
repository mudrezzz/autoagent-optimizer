# Release Note: V2.4.S5

## Slice

`V2.4.S5 - Dataset v2 schema (stage-aware targets)`

## User-visible Changes

1. C4 dataset rows now support `target_stage` with values `retrieval | rerank | synthesis | final`.
2. C4 editor now includes `target_stage` column.
3. Dataset API now stores stage-specific `expected_payload` per row.
4. Validation now reports stage-specific warnings/errors for incomplete expected payloads.

## Why

Different evaluation metrics need different ground-truth contracts. Final-answer-only rows are not enough for retrieval/rerank/synthesis diagnostics.

## Technical Summary

1. Added stage-aware normalization in `optimizer.workspace.registry_store`:
- `target_stage` normalization,
- `expected_payload` coercion from legacy `expected`.
2. Extended dataset validation rules with stage-specific checks.
3. Updated frontend C4 editor and JSONL import to edit/save stage-aware rows.
4. Updated integration/unit tests for dataset v2 contract.
