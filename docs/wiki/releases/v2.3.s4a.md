# Release Note: V2.3.S4a

## Slice

`V2.3.S4a - UX corrective: unified checkbox selection (C2/C3)`

## User-visible Changes

1. Removed `Include / Exclude / Clear` from C3.
2. Added one selection checkbox per pattern row.
3. Added shared `Save` button above pattern list.
4. Unified the selection model with C2: `select -> save`.

## Why

To remove cognitive friction between similar selection actions and speed up work in Battle Workspace.

## Technical Summary

1. Switched C3 UI component to single-checkbox interaction.
2. C3 selection API contract remained unchanged.
3. Added frontend test for explicit `Save` behavior.
