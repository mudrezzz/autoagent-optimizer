# Release Note: V2.3.S4a

## Slice

`V2.3.S4a - UX corrective: unified checkbox selection (C2/C3)`

## User-visible changes

1. В C3 кнопки `Include / Exclude / Clear` заменены на чекбоксы `Include / Exclude`.
2. Модель взаимодействия выбора стала одинаковой в C2 и C3.

## Why

Чтобы убрать когнитивный разрыв между близкими действиями выбора и ускорить работу пользователя в Battle Workspace.

## Technical summary

1. UI-компонент C3 обновлен на checkbox-based interaction.
2. API контракт C3 selection не менялся.
3. Добавлен frontend-тест на сохранение C3 include selection.
