# Release Note: V2.3.S4a

## Slice

`V2.3.S4a - UX corrective: unified checkbox selection (C2/C3)`

## User-visible changes

1. В C3 убраны `Include / Exclude / Clear`.
2. Добавлена одна галочка выбора на строку паттерна.
3. Добавлена общая кнопка `Save` над списком паттернов.
4. Модель выбора стала одинаковой с C2: `select -> save`.

## Why

Чтобы убрать когнитивный разрыв между близкими действиями выбора и ускорить работу пользователя в Battle Workspace.

## Technical summary

1. UI-компонент C3 переведен на single-checkbox interaction.
2. API контракт C3 selection не менялся.
3. Добавлен frontend-тест на явное сохранение через `Save`.
