# Release Note: V2.3.S4

## Slice

`V2.3.S4 - Candidate assembly + internal compile readiness`

## User-visible changes

1. Добавлены чекбоксы выбора кандидатов в C2.
2. Добавлено действие `Select for tests`.
3. Валидация/компиляция перенесены во внутренний процесс.

## Why

Чтобы пользователь работал с продуктовым действием (отбор кандидатов), а не с техническими шагами подготовки.

## Technical summary

1. Новый endpoint `POST /api/arenas/{id}/candidates/select-for-tests`.
2. Внутренний retry + auto-fix перед выдачей issue.
3. Обновлены unit/integration/frontend тесты.
