01 · Brand identity

A friendly mark for a measurable product.

The mark is a solid indigo tile containing three connected nodes — a stylized compound architecture, with the champion node enlarged at the top. It reads as "network", "structure", "best of many" — without ever shouting "AI".

Logo lockup & mark

Primary lockup · on light backgrounds
Lockup on dark surfaces
Mark only — favicon, avatar, app icon
Mark on dark — sidebar / hero

Construction

PropertyValueNote
Tile shaperounded square · rx = 14 pxFriendly, modern. Never sharp-cornered.
Tile color#635BFF · indigo-500Brand indigo. Solid — never gradient.
Glyph3 nodes + triangle outlineTop node = champion, larger, indigo dot.
Glyph colorwhite at 0.55 opacityLines; nodes are full opacity white.
WordmarkGeist 600 + Geist 400"AutoAgent" bold, "Optimizer" subtle.
Clear space≥ 12 px around mark · ≥ 24 px around lockupNever crowd it.
Minimum sizemark ≥ 24 px · lockup ≥ 120 px wideBelow that, switch to mark only.

Do & don't

Do
  • Use on a clean white, gray-50, or solid dark background.
  • Maintain 12 px+ clear space on all sides.
  • Use the inverse mark on dark surfaces (gray-900 only).
  • Keep the indigo tile pure #635BFF — no tints, no gradient.
Don't
  • Place on photography, AI-generated imagery, or busy backgrounds.
  • Stretch, skew, rotate, or recolor the tile or glyph.
  • Add drop-shadows, glow effects, or "AI-style" gradients.
  • Use the lockup below 120 px wide — switch to the mark.
02 · Color system

One indigo, eleven neutrals, four status colors.

Hierarchy lives in the neutrals. The single indigo accent marks the one thing in a view that matters — primary action, champion, focus. Status colors are reserved for state, never decoration.

Color rules

Do
  • Reserve indigo for the one thing in a view that matters most.
  • Build hierarchy from four ink tiers (900 / 700 / 500 / 400).
  • Use status colors only on status indicators (pills, dots, deltas).
  • Solid colors only — pure flat fills.
Don't
  • Use bluish-purple gradients or any AI-glow gradients.
  • Decorate with status colors (e.g. red icons for non-error items).
  • Tint indigo onto large backgrounds (max ~12 % opacity for accent bg).
  • Mix multiple accent colors in one view.

One family does the whole system.

07 · Voice & content

Friendly + technological. Numbers carry the message.

The way Stripe and Vercel talk in their product UI — direct, clear, low-jargon, no marketing slop. No emoji, anywhere. No AI mysticism.

Tone characteristics

Lean towardAvoid
Direct, plain-English engineering terms"Empower", "unleash", "supercharge"
Sentence case, friendly imperative verbsTITLE CASE MARKETING SHOUTS
Concrete measurements (numbers, deltas, units)Vague magic ("intelligent", "AI-powered")
Honest tradeoffs (e.g. +0.04 f1 vs +12 m human time)Overclaiming, hyperbolic language
Code, identifiers, metrics in monospaceParaphrasing technical terms in prose

Example copy

Do
  • "Design many architectures. Ship the one that proves itself."
  • "No runs yet. Start your first run to bracket the design space."
  • "Champion → arch_b4f · +4.2 f1, −38 % cost · Evidence exported."
  • "Trace shows 14 LLM calls. Retriever drives 62 % of p95."
Don't
  • "Unleash the power of AI to supercharge your workflow!"
  • "✨ Welcome! Let's get started on your AI journey 🚀"
  • "Our intelligent system delivers next-generation performance."
  • "AI-powered. Game-changing. Revolutionary."

Numbers, units, deltas

RuleExample
Percentages with en-dash, space before %−38 % · +24 %
Metric deltas always carry sign+4.2 · −1.7 · +0.038
Time: lowercase units, space between number and unitp95 1.2 s · 14 m human time
Counts: lowercase k for thousands24 candidates · 1.2 k traces
Money in code blocks, no space around $cost <= $0.40 · $24.80

09 · App interface example

The workbench.

Three-column layout: sidebar (264 px) · main · intervention rail (340 px). Top bar has crumb, budget meter, search + actions. Champion is highlighted with an indigo gradient row + pill. The trace viewer below uses the same span-type colors as the rest of the system.

In the top bar — indigo fill on gray track. Always shows current spend / cap and per-case constraint.

Architecture list

How to use in a new project

  1. Copy colors_and_type.css and the assets/ folder to your project.
  2. Link the stylesheet: <link rel="stylesheet" href="colors_and_type.css">
  3. Load Lucide for icons: <script src="https://unpkg.com/lucide@latest/dist/umd/lucide.min.js"></script>
  4. Use the CSS variables: color: var(--accent), background: var(--gray-50), etc.
  5. For components, copy markup from preview/comp-*.html or React components from ui_kits/.
