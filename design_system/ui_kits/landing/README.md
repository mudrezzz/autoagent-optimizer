# Landing UI kit — AutoAgent Optimizer

Marketing landing page. Stripe-soft + Vercel-clean direction: white background, soft shadows, generous whitespace, friendly indigo accent.

**Structure**
- `index.html` — full landing assembled
- `Nav.jsx` — sticky nav with logomark, links, star count, sign in, CTA
- `Hero.jsx` — display headline with indigo accent + sub + dual CTA + product demo card on the right + trust logos
- `Features.jsx` — 3-up feature grid (Generate / Measure / Optimize) with tinted icons
- `Philosophy.jsx` — quote + 3 supporting tiles
- `ProofMatrix.jsx` — architecture comparison table with status pills
- `CTA.jsx` — dark CTA card with radial indigo glow + install command
- `Footer.jsx` — brand + 4 link columns + bottom bar
